# Minigames 3 - MCFunction Project

🎉 Welcome to **Minigames 3**!  

This project was originally created to simplify Minecraft maps by replacing most command blocks with **mcfunction files**. Over time, the original Minecraft map was removed, but the mcfunction scripts remain available for **learning and exploration**.  

Even without the map, these files are a great way to see how complex Minecraft logic can be implemented in a cleaner, modular way. Whether you’re curious about scoreboards, selectors, or in-game mechanics, there’s a lot to study and experiment with!  

---

## ⚡ Highlights

- ✅ **Command block reduction** – clean and modular mcfunction scripts  
- 🎯 **Minigame mechanics** – functions designed to handle different in-game logic  
- 📚 **Learning-focused** – perfect for studying Minecraft commands and logic  

---

## 💡 Notes

- The original Minecraft map is **not included**.  
- These scripts are mainly for **learning and experimentation**.  
- Feel free to **study, modify, or remix** to better understand Minecraft command logic.
